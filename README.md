# ONDA Claude Code plugins

A Claude Code plugin marketplace from ONDA.

```
claude plugin marketplace add ondame/claude-plugins
claude plugin install onda-developer-center@ondame
```

| Plugin | What it does |
|---|---|
| [`onda-developer-center`](plugins/onda-developer-center) | Configure the ONDA Developer Center and call the Channel and Supply APIs through the `ondadc` MCP server. Requires `ondadc` 0.2.0+ (`brew install ondame/tap/onda-developer-center`) and one `ondadc auth login`; macOS and Linux. |
